# Arcade Poker - デザイン計画

## コンセプト
80〜90年代のアーケードゲーム機を彷彿とさせるネオンカラー・ダークテーマのポーカーゲーム。
「Video Poker」スタイル（5枚カードドロー）を採用し、コイン制でスコアを競う。

---

## スクリーン一覧

| スクリーン | 説明 |
|-----------|------|
| **ホーム (Home)** | タイトル画面・コイン残高表示・ゲーム開始ボタン |
| **ゲーム (Game)** | メインのポーカーゲーム画面 |
| **ペイテーブル (PayTable)** | 役一覧と配当表 |
| **ランキング (Ranking)** | ハイスコア・最大コイン記録 |

---

## 各スクリーンの詳細

### ホーム画面
- アーケード風ネオンタイトル「ARCADE POKER」
- 現在のコイン残高（大きく表示）
- 「PLAY」ボタン（大型・光るエフェクト）
- 「PAY TABLE」「HIGH SCORE」へのナビゲーション
- 背景：暗い緑のフェルト風テクスチャ + ネオンライン

### ゲーム画面
- **ベット選択エリア**：1/5/10/25/50コインのベットボタン
- **カード表示エリア**：5枚のカード（横並び）、各カードにHOLD/DISCARD選択
- **アクションボタン**：「DEAL / DRAW」大型ボタン
- **役表示エリア**：現在の役名をネオン文字で表示
- **コイン残高・ベット額**：画面上部に常時表示
- **WIN表示**：役が成立したときのネオン演出

### ペイテーブル画面
- 役名（日本語・英語）と配当倍率一覧
- 現在のベット額に基づいた実際の払い出し額
- アーケード風テーブルデザイン

### ランキング画面
- ローカルハイスコア（最大コイン到達額）
- 最高役の記録
- プレイ回数

---

## 主要ユーザーフロー

```
ホーム → ゲーム開始
  → ベット選択 → DEAL（5枚配布）
  → HOLD/DISCARD選択 → DRAW（交換）
  → 役判定 → WIN演出 or LOSE
  → 次のラウンドへ / コイン0でゲームオーバー
```

## カードデザイン

- 白地に赤・黒のスーツ（♠♥♦♣）
- スーツ記号は大きく中央表示
- HOLDされたカードは金色のボーダー + 「HOLD」バッジ
- カードフリップアニメーション（表裏）

---

## アーケードUI要素

- ネオングロウエフェクト（text-shadow / box-shadow）
- ピクセル風フォント（monospace系）
- コイン獲得時のキラキラエフェクト
- ボタン押下時のハプティクスフィードバック
- 役成立時のフラッシュアニメーション
- 「INSERT COIN」風のアイドル演出
